# Storebox File Explorer

A small React + Vite frontend app that implements a VS Code-style file explorer.

## Features

- Create a new file at the root
- Create a new folder at the root
- Add files and folders inside folders
- Rename files and folders
- Delete files and folders
- Edit file content in the detail panel

## Setup

1. Install dependencies

```bash
cd "d:\new project"
npm install
```

2. Run the development server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

## Notes

- The project uses Vite with React and TypeScript.
- The app is intentionally lightweight and avoids ready-made tree libraries.
